Objetivos del proyecto:
  1. Objetivo general:
    Desarrollar una solución a una empresa para gestionar curriculums de forma mas eficiente Posible. Tambien permitir almacemar, organizar, consultar y filtrar la información de forma rapida, segura y sostenible.
  2. Objetivos especificos:
     2.1 Organizar la información de los candidatos:
       Crear una estructura que pueda almacenar los datos de las personas, curriculums, títulos, etc...
     2.2 Diseñar una base de datos bien estructurada
       Crear tablas, establecer bien las relaciones, evitar redundanias, organizar todo bien y hacer que sea lo más eficiente posible.
     2.3 Facilitar la búsqueda de candidatos
       Permitir localizar a los diferentes candidatos de forma sencilla y rápida. Tambíen cualquier tipo de atributo que sea o no de los candidatos.
     2.4 Gestionar los curriculums de forma digital  
       Permitir almacenar, consultar y etc. Los curriculums que sean enviados de forma digital, haciendolos mas faciles de localizar y asi evitar tener que usar documentos fisicos.
     2.5 Integridad
       Definir todo bien y correcto respecto a los atributos identificadores y descriptivos, las claves candidatas, primarias y las relaciones.
     2.6 Proteger los datos
       Poner medidd de seguridad para respetar la protección de datos, haciendo todo lo posible para proteger la información, especialmente los datos personales de los candidatos
     2.7 Mejorar la eficiencia de la selección de candidatos
       Reducir el tiempo que la empresa le dedique a organizar, mirar y evaluar los curriculums, usando diferentes metodos con algoritmos y filtros para facilitar el trabajo de revisión.
     2.8 Fomentar la digitalizacion
       Teniendo todo de forma digital guardado, se reduce el consumo de papel, asi se evita usar papel innecesario, imprimir mas de la cuenta y se mejora la gestión de forma digital.
     2.9 Comparaciones
       Consultar la documentacion para comparar alternativas y justificar las decisionds que se toman a lo largo del proyecto. Tambien documentarlo todo.
     2.10 Trabajar en equipo
       Organizar el trabajo, para trabajar mas eficientemente, repartir responsabilidades, los conocimientos que vayamos adquiriendo pro el camino y desarrollar el proyecto juntos.
  3. El resutado que esperamos
     Cuando acabe el proyecto esperamos ya tener el programa finalizado, con todas las caracteristicas de almacenamiento, administración, consultas de información, gestión de candidatos, acceso a la información rapido y etc. Tambíen conseguir terminar la herramienta que ayuda el proceso de selección de candidatos dentro de lo que podamos
