TalentConnect - Frontend
Esta carpeta contiene la página web de TalentConnect, desarrollada con HTML, CSS, JavaScript, React y Vite.

Instalación
Para ejecutar la página es necesario tener instalado Node.js, que incluye npm.
Descargar desde: https://nodejs.org/
Una vez instalado, abrir el proyecto en VS Code y acceder a la carpeta Web.

En la terminal, ejecutar:
npm install
npm run dev

El primer comando instala las dependencias necesarias y el segundo inicia la página.
Para verla, abrir el enlace que aparece en la terminal, normalmente http://localhost:5173/.

Importante
No es necesario instalar React por separado.
La carpeta node_modules se genera con npm install y no se sube a GitHub.
Para detener el servidor, pulsar Ctrl + C.
Rama: feature/html-frontend.
